DualShield Hybrid Authentication Protocol (DHAP) - A novel hybrid cryptosystem based authentication protocol between two parties

Affiliation: University of Ruhuna (2023 - 2024)

DualShield Hybrid Authentication Protocol (DHAP) is a novel hybrid cryptosystem that combines RSA and AES encryption techniques for secure digital communication. The protocol operates in two phases: mutual authentication using RSA-signed challenge-response mechanisms, and secure communication using AES encryption. DHAP addresses fundamental challenges in cryptographic systems including secure key distribution and computational efficiency. The system is particularly suited for financial transactions, secure online communication, and enterprise-level data exchange systems requiring both high security and performance.

Mathematical Model to Evaluate the Speed of Competitive Swimmers

Affiliation: University of Ruhuna (2023 - 2024)

This project develops a comprehensive mathematical model that accurately predicts the speed of competitive swimmers by analyzing the complex interplay between physical, physiological, and technical aspects. The model considers factors such as stroke mechanics, stroke rate, stroke length, swimmer's cross-sectional area, and drag resistance. Using dimensional analysis and the Buckingham π theorem, the research derives a final equation: V = (SR) * ∜(SL/A) where V is velocity, SR is stroke rate, SL is stroke length, and A is cross-sectional area. The model was validated using data from elite swimmers and provides valuable insights for coaching and performance optimization in competitive swimming.
